# 01 · 环境搭建与本地运行（Windows / macOS）

> 目标：装好 Flutter 开发环境，把本项目跑在 Android 与 iOS 真机 / 模拟器上。

---

## 1. 安装 Flutter SDK

### 1.1 下载
- 官网：https://docs.flutter.dev/get-started/install
- 国内镜像（推荐，下载快）：
  - Flutter SDK 镜像：https://flutter.cn/docs/get-started/install
  - 或清华镜像：https://mirrors.tuna.tsinghua.edu.cn/flutter/flutter_infra_release/releases/

解压到**不含中文与空格**的目录，例如：
- Windows：`D:\dev\flutter`
- macOS：`~/dev/flutter`

### 1.2 配置环境变量
把 `flutter/bin` 加入 PATH：

```bash
# Windows（PowerShell，管理员权限，永久生效）
setx PATH "$env:PATH;D:\dev\flutter\bin" -m

# macOS / Linux（写入 ~/.zshrc 或 ~/.bash_profile）
export PATH="$HOME/dev/flutter/bin:$PATH"
```

### 1.3 配置国内镜像（国内网络必做）
```bash
# Windows PowerShell
setx PUB_HOSTED_URL "https://pub.flutter-io.cn" -m
setx FLUTTER_STORAGE_BASE_URL "https://storage.flutter-io.cn" -m

# macOS / Linux
export PUB_HOSTED_URL=https://pub.flutter-io.cn
export FLUTTER_STORAGE_BASE_URL=https://storage.flutter-io.cn
```

### 1.4 验证与升级（**版本要求较严格，请先升级**）
本项目依赖包使用的是当前最新稳定版，要求：

| 项目 | 最低要求 |
| --- | --- |
| Flutter SDK | **≥ 3.44.0** |
| Dart SDK | ≥ 3.11.0 |

```bash
flutter --version
dart --version

# 版本不够时升级（切到 stable 通道后升级）
flutter channel stable
flutter upgrade

# 升级后再次确认
flutter --version
```

> 若确实无法升级，可把 `pubspec.yaml` 中的依赖版本号整体下调（例如
> `flutter_local_notifications: ^17.2.3`、`audioplayers: ^5.2.1`），
> 但部分 API 名称会不同（如旧版 `initialize()` 第一个参数为位置参数），需要按 IDE 报错微调。

## 2. 安装平台工具链

### 2.1 Android（Windows / macOS / Linux 都需要）
1. 安装 [Android Studio](https://developer.android.com/studio)
2. 打开 Android Studio → **Settings → Android SDK**：
   - 勾选 **Android SDK Platform 35**（对应 `compileSdk = 35`）
   - 勾选 **Android SDK Command-line Tools**
   - 勾选 **Android SDK Build-Tools**
3. 安装 **Flutter** 与 **Dart** 插件（Android Studio 插件市场）
4. 接受许可协议：
   ```bash
   flutter doctor --android-licenses   # 一路输入 y
   ```

### 2.2 iOS（**仅 macOS**，Windows 无法编译 iOS）
1. 安装 Xcode（App Store，需 15.0 以上）
2. 安装 CocoaPods：
   ```bash
   sudo gem install cocoapods
   # 或（推荐，M 系列芯片）
   brew install cocoapods
   ```
3. 首次打开 Xcode 会提示安装组件，点 Install；然后执行一次：
   ```bash
   sudo xcode-select --switch /Applications/Xcode.app/Contents/Developer
   sudo xcodebuild -runFirstLaunch
   ```

### 2.3 环境体检
```bash
flutter doctor -v
```
出现 `No issues found`（或只剩"未连接设备"）即表示环境 OK。

## 3. 生成原生工程并合并本项目文件

本项目提供了 `lib/`、`assets/`、`pubspec.yaml` 与**安卓 / iOS 的关键配置文件**，
但 Gradle 与 Xcode 工程脚手架（约几十个文件）由 Flutter 官方模板生成最稳妥。
**请按以下步骤操作，不要直接 `flutter create .`（可能覆盖已有文件）：**

### 3.1 用官方模板生成一份干净的原生工程
```bash
cd ~/Desktop
flutter create --org com.example --project-name work_memo_alarm --platforms=android,ios tmp_scaffold
```
> 包名（`--org`）可改成你自己的域名倒序，例如 `--org com.yourcompany`。
> 若改成其他包名，请同步修改 `android/app/build.gradle` 的 `applicationId`
> 与 `MainActivity.kt` 的 `package`，以及 `android/app/src/main/kotlin/` 下的目录层级。

### 3.2 拷贝原生目录到本项目
```bash
# 假设本项目路径为 <PROJECT>
cp -r tmp_scaffold/android <PROJECT>/android
cp -r tmp_scaffold/ios    <PROJECT>/ios
```
> 覆盖时若提示文件已存在，选择**保留本项目提供的版本**（即下面 3.3 的文件）。

### 3.3 用本项目提供的文件覆盖这些路径
| 本项目文件 | 覆盖到 |
| --- | --- |
| `android/app/build.gradle` | `android/app/build.gradle` |
| `android/app/src/main/AndroidManifest.xml` | 同名路径 |
| `android/app/src/main/kotlin/com/example/work_memo_alarm/MainActivity.kt` | 同名路径（若改了包名需同步调整目录） |
| `android/app/src/main/res/values/styles.xml` | 同名路径 |
| `ios/Runner/AppDelegate.swift` | `ios/Runner/AppDelegate.swift` |
| `ios/Runner/Info.plist` | `ios/Runner/Info.plist` |
| `ios/Podfile` | `ios/Podfile` |
| `android/app/src/main/res/raw/*.wav` | 同名路径（已放置，勿删） |

## 4. 放置铃声资源（**不做这步 iOS 通知不会响**）

铃声文件已经生成好，位置：

| 位置 | 用途 |
| --- | --- |
| `assets/ringtones/*.wav` | App 内响铃页循环播放（已在 pubspec 中声明） |
| `android/app/src/main/res/raw/alarm_*.wav` | Android 通知铃声（已放置，无需操作） |
| `ios/Runner/Ringtones/alarm_*.wav` | **iOS 通知铃声，需要在 Xcode 中手动加入** |

### iOS 手动添加步骤
1. 用 Xcode 打开 `ios/Runner.xcworkspace`
2. 左侧选中 `Runner` → 目标 `Runner` → **Build Phases** → **Copy Bundle Resources**
3. 点击 `+` → **Add Other…** → 选择 `ios/Runner/Ringtones/` 下的 4 个 wav 文件
4. 确认这 4 个文件出现在列表中（必须位于**主 bundle 根目录**，不能放在子文件夹里）

> 原因：iOS 的本地通知声音只能读取 App 主 bundle 根目录下的音频文件，
> 无法访问 Flutter 的 `flutter_assets` 资源目录。

## 5. 安装依赖并运行

```bash
cd <PROJECT>
flutter pub get

# 查看可用设备
flutter devices

# 运行到指定设备
flutter run -d <deviceId>

# 常用：直接运行安卓 / iOS
flutter run -d android
flutter run -d iphone      # macOS 且已连接 iPhone 或已启动模拟器
```

首次运行会下载 Gradle 依赖（安卓）与 CocoaPods 依赖（iOS），耗时 5~20 分钟，属正常现象。

## 6. 调试建议

| 场景 | 建议 |
| --- | --- |
| 想快速验证闹钟 | 新建一个"一次性"闹钟，时间设为 **1~2 分钟后**，然后把 APP 退到后台等待 |
| 查看已注册的通知 | 设置页 → 「重新注册全部闹钟」后，用 `adb shell dumpsys alarm \| grep work_memo` 查看 |
| 热重载 | 运行中输入 `r`；热重启输入 `R` |
| 查看日志 | `flutter logs` 或 Android Studio / Xcode 控制台 |

## 7. 常见问题

| 问题 | 解决方式 |
| --- | --- |
| `Waiting for another flutter command to release the startup lock` | 删除 `flutter/bin/cache/lockfile` 后重试 |
| Gradle 下载卡住 | 修改 `android/settings.gradle` 与根 `build.gradle` 的 `repositories` 为阿里云镜像：`maven { url 'https://maven.aliyun.com/repository/google' }` 等 |
| `CocoaPods not installed` | 执行 `sudo gem install cocoapods`（M 芯片用 `brew install cocoapods`） |
| iOS 真机报签名错误 | Xcode → Runner → Signing & Capabilities → 勾选 **Automatically manage signing**，选择自己的 Apple ID |
| 安卓模拟器无通知声音 | 模拟器音量易被静音，建议用真机测试 |
| `Target of URI doesn't exist: package:flutter/...` | 执行 `flutter pub get` 后重启 IDE |
