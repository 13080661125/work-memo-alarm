# 04 · 项目结构、数据流与二次开发指南

---

## 1. 整体数据流

```
┌──────────────── UI 层（pages / widgets） ────────────────┐
│  HomePage（底部两个 Tab：备忘录 / 闹钟）                  │
│     ├─ MemoListPage ─── MemoEditPage ─┐                  │
│     └─ AlarmListPage ── AlarmEditPage │                  │
│                                        ▼                 │
│                              AlarmRingingPage（全屏响铃） │
└───────────────┬──────────────────────────────────────────┘
                │  context.watch / context.read
┌───────────────▼────────── 状态层（providers） ───────────┐
│  MemoProvider（搜索 / 排序 / 增删查）                     │
│  AlarmProvider（增删查 + 同步系统通知）                   │
└───────────────┬──────────────────────────────────────────┘
                │
┌───────────────▼────────── 服务层（services） ────────────┐
│  StorageService      → SharedPreferences（JSON 持久化）   │
│  NotificationService → 系统定时通知（闹钟核心）           │
│  RingingService      → 铃声循环播放 + 震动               │
│  PermissionService   → 双端权限申请与自检                 │
└───────────────────────────────────────────────────────────┘
```

**数据一致性原则**：备忘录不保存提醒时间，只保存 `alarmId`；
真正的提醒时间统一存在 `Alarm` 里，避免两处数据不同步。

## 2. 闹钟触发全链路（排障必看）

```
① 用户保存闹钟
   AlarmProvider.add/update
        │
        ▼
② NotificationService.scheduleAlarm(alarm)
   - 重复闹钟：为每个选中星期注册一条通知
     id = notifBase + 星期（1~7），matchDateTimeComponents = dayOfWeekAndTime
   - 一次性闹钟：注册一条，id = notifBase
   - 统一使用 AndroidScheduleMode.exactAllowWhileIdle
   - Android：fullScreenIntent = true
   - iOS：interruptionLevel = timeSensitive + 通知分类（关闭/贪睡按钮）
        │
        ▼
③ 到点，系统投递通知
        │
        ├─ Android 锁屏 → 全屏意图直接拉起 MainActivity → 打开响铃页
        ├─ 用户点击通知 → onDidReceiveNotificationResponse
        └─ 用户点通知按钮 → actionId = snooze / stop
        │
        ▼
④ HomePage 收到事件
   - stop   → AlarmProvider.stopRinging()（一次性闹钟自动关闭）
   - snooze → AlarmProvider.snooze() 注册 10 分钟后的新通知
   - 点击主体 → 打开 AlarmRingingPage
        │
        ▼
⑤ AlarmRingingPage
   RingingService.start()（循环铃声 + 循环震动）
   - 关闭 → stop + 一次性闹钟自动置为关闭
   - 贪睡 → 注册 +10min 通知并返回
```

**通知 ID 分配规则**（`NotificationConfig.idSpanPerAlarm = 10`）：

| ID | 用途 |
| --- | --- |
| `notifBase + 0` | 一次性闹钟 |
| `notifBase + 1 ~ 7` | 周一 ~ 周日各自的重复通知 |
| `notifBase + 8` | 贪睡通知 |

`notifBase` 由 `StorageService.nextNotifBase()` 递增分配并持久化，
保证 APP 重启后 ID 不变，才能精确取消。

## 3. 常见二次开发点

### 3.1 新增铃声
1. 生成/准备 wav（可用 `tools/generate_ringtones.py` 改造，时长建议 ≤ 5 秒）
2. 放入 `assets/ringtones/xxx.wav`
3. 拷贝到 `android/app/src/main/res/raw/alarm_xxx.wav`（**全小写下划线**）
4. 拷贝到 `ios/Runner/Ringtones/alarm_xxx.wav` 并在 Xcode 加入 Copy Bundle Resources
5. 在 `lib/constants/app_constants.dart` 的 `kRingtones` 里加一行：
   ```dart
   RingtoneItem(
     id: 'xxx',
     name: '我的铃声',
     assetPath: 'ringtones/xxx.wav',
     nativeName: 'alarm_xxx',
   ),
   ```
   > 通知渠道在 `NotificationService._createAndroidChannels()` 中按铃声自动创建，无需改代码。

### 3.2 修改主题配色
改 `lib/constants/app_constants.dart` 的 `AppColors`，全局生效；
更细的组件样式在 `lib/app.dart` 的 `_buildTheme()`。

### 3.3 修改贪睡时长
`app_constants.dart` → `NotificationConfig.snoozeMinutes`（当前 10）。
UI 文案同步改 `alarm_ringing_page.dart` 的按钮文字。

### 3.4 换成数据库存储
数据量变大时，把 `StorageService` 的实现替换为 sqflite / isar 即可，
`MemoProvider` / `AlarmProvider` 的业务代码不用动（它们只依赖 StorageService 的接口）。

### 3.5 增加"闹钟响铃时长"
`alarm_ringing_page.dart` 中有一个 2 分钟自动停止的兜底定时器：
```dart
_autoStopTimer = Timer(const Duration(minutes: 2), () { ... });
```
改这个常量即可。

### 3.6 增加分类/标签
在 `Memo` 模型加 `String? category` 字段 → `toJson/fromJson` 同步 →
列表页加筛选 chips → 编辑页加输入。参考优先级字段的实现方式。

## 4. 关键设计取舍说明

| 取舍 | 选择 | 原因 |
| --- | --- | --- |
| 存储 | SharedPreferences + JSON | 数据量小、零配置、双端一致；换 sqflite 也不难 |
| 闹钟实现 | 系统定时通知（非前台服务） | 更省电、更抗杀，是闹钟/提醒类 App 的标准做法 |
| 状态管理 | provider | 官方推荐、学习成本低、足够本项目规模 |
| 铃声 | 代码合成 wav | 无版权风险，且体积极小（单文件 ~180KB） |
| 提醒数据归属 | 统一到 Alarm 模型 | 避免备忘录与闹钟两份时间不同步 |

## 5. 已知边界与后续优化建议

1. **iOS 64 条通知上限**：重复闹钟按星期注册，最多 7 条/个，建议不超过 9 个重复闹钟。
   如需支持更多，可改为"只注册最近一次触发 + 响铃后再注册下一次"的滚动调度方案。
2. **一次性闹钟时间已过**：本项目自动顺延到第二天，UI 上有提示文案。
3. **时区变化**：APP 每次启动会重新注册全部闹钟，跨时区旅行后基本无感；
   若要更严谨，可监听系统时区广播后调用 `AlarmProvider.rescheduleAll()`。
4. **多设备同步**：当前是纯本地存储；如需云同步，只需把 `StorageService` 换成
   "本地 + 云端"双写实现，其余代码不受影响。
