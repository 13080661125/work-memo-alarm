# 浏览器版：不装 App，手机直接打开

`web_preview/` 目录里是一个**纯 HTML 单文件应用**，界面与功能和原生 Flutter App 一致。
不需要 Flutter 环境、不需要打包，浏览器打开就能用。

```
web_preview/
├── index.html       # 全部代码（HTML + CSS + JS），约 1000 行
├── manifest.json    # 支持"添加到主屏幕"，全屏运行像原生 App
└── icon.svg         # 图标
```

---

## 一、三种打开方式（按推荐顺序）

### 方式 1：本机同 WiFi，手机立刻打开（最快，无需网络服务）

电脑上已经启动了本地服务，手机和电脑连**同一个 WiFi** 时：

```
http://192.168.0.112:8080
```

> IP 会随路由器变化。查本机当前 IP：
> ```bash
> ipconfig | findstr IPv4
> ```
> 启动服务（在 `web_preview` 目录执行）：
> ```bash
> python -m http.server 8080 --bind 0.0.0.0
> ```
> 若手机打不开，多半是防火墙拦了，用**管理员身份**运行 PowerShell 执行：
> ```powershell
> netsh advfirewall firewall add rule name="WorkMemoPreview8080" dir=in action=allow protocol=TCP localport=8080
> ```
> 优点：零配置、改代码刷新即生效。缺点：电脑关机就打不开，且只能在同一局域网。

### 方式 2：GitHub Pages 永久网址（推荐长期使用）

一次配置，之后每次 `git push` 自动更新，网址固定不变，任何网络都能访问。

**第 1 步（仅一次）**：GitHub 仓库 → `Settings` → 左侧 `Pages` → `Source` 选 **GitHub Actions** → Save。

**第 2 步**：推送代码

```bash
git add .
git commit -m "新增浏览器版"
git push
```

**第 3 步**：`Actions` 页面等「部署浏览器版到网页」变绿 → 打开 `Settings → Pages` 顶部的网址，
格式为 `https://<用户名>.github.io/<仓库名>/`。

> 仓库为 Private 时，Pages 网址别人也能访问（内容仍是公开的），介意的话改用方式 1 或 3。

### 方式 3：直接双击 index.html

双击 `web_preview/index.html`，用 Chrome / Edge 打开即可。
数据存在浏览器本地，能正常保存；只是"添加到主屏幕"功能不可用（需要 http 服务）。

## 二、手机上添加到主屏幕（像 App 一样）

用手机浏览器打开网址后：

| 手机 | 操作 |
|---|---|
| 安卓 Chrome | 右上角 ⋮ → **添加到主屏幕** / 安装应用 |
| iPhone Safari | 底部分享按钮 → **添加到主屏幕** |

添加后桌面出现图标，点开是**全屏无地址栏**的界面，和原生 App 观感一致。
数据存在手机本地，关掉再打开不会丢。

## 三、浏览器版能做什么

- 备忘录：新建/编辑/删除、标题+正文、**高中低优先级**（左侧色条）、**待办勾选**、**标题与正文实时搜索**、4 种排序（最新/最早/优先级高→低/低→高）
- 闹钟：多条闹钟、**24 小时制**、周一~周日多选重复（每天/工作日/周末/单次）、**4 种内置铃声可试听**、震动开关、启用开关、**贪睡 10 分钟**、实时显示"下次响铃时间"
- 联动：在备忘录里可直接绑定提醒闹钟，闹钟列表会标注"来自备忘录"
- 响铃：全屏响铃页 + 铃声 + 震动，两个按钮「关闭提醒 / 贪睡 10 分钟」
- 铃声是**实时合成的**（Web Audio），不需要下载任何音频文件

## 四、浏览器版的限制（重要）

| 限制 | 原因 | 影响 |
|---|---|---|
| 页面必须保持打开 | 浏览器不允许网页在关闭后执行代码 | 关掉标签页 → 闹钟不响 |
| 后台可能延迟 | 浏览器会限制后台标签页的定时器频率 | 切到后台时可能晚几十秒到 1 分钟 |
| iPhone 不能震动 | iOS Safari 不支持网页震动 API | 有铃声，无震动 |
| iOS 后台限制更严 | 苹果不允许网页后台持续运行 | iPhone 上建议一直把页面留在前台 |

**结论**：浏览器版适合**立刻体验、日常记录、临时提醒**；
需要"锁屏也能响、到点必响、开机自恢复"的可靠闹钟，还是要装原生 App（安卓 APK / 苹果 IPA，见 `docs/05`）。

## 五、数据存储在哪

浏览器 `localStorage`，三个键：

| 键 | 内容 |
|---|---|
| `wma_memos_v1` | 备忘录列表 |
| `wma_alarms_v1` | 闹钟列表 |
| `wma_cfg_v1` | 铃声、震动等设置 |

- 换浏览器 / 清理浏览数据 / 无痕模式 → 数据会丢，重要内容注意备份
- 手机和电脑的数据**各自独立**，不同步

---

## 六、与 Flutter 原生版的关系

两者**互相独立**：

- 浏览器版 = 快速预览 + 日常使用，改动在 `web_preview/index.html`
- 原生版 = 真后台闹钟 + 通知栏 + 开机恢复，改动在 `lib/`

如果只想改界面文案/配色这类小调整，改浏览器版更快（刷新即见效）；
涉及闹钟可靠性、通知、锁屏弹窗的功能，必须改原生版并重新打包。
