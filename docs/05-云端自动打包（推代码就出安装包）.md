# 05 · 云端自动打包：推上 GitHub，自动出安装包

> 适合：**本机不想装 Flutter 环境**（下载 6GB+、耗时长）。
> 原理：GitHub 提供免费云主机，代码推上去后自动编译，你在网页上直接下载安装包。
>
> - 安卓：下载 APK → 传到手机 → 安装 → **马上能用** ✅
> - 苹果：云端只能出"未签名包"，**必须再用 Mac 签名**才能装 iPhone（原因见第五节）

---

## 第 1 步：注册 GitHub 并建仓库（约 3 分钟）

1. 打开 https://github.com 注册账号（已有账号直接登录）
2. 右上角 `+` → **New repository**
3. 填写：
   - **Repository name**：`work-memo-alarm`
   - **Public / Private**：
     - 选 **Public（公开）**：构建时长**完全免费无限**，但代码公开可见
     - 选 **Private（私有）**：代码保密，免费额度 **2000 分钟/月**（安卓一次约 8 分钟，够用几十次）
   - **不要**勾选 "Add a README file"（我们已有文件）
4. 点 **Create repository**
5. 页面上会显示你的仓库地址，形如：
   ```
   https://github.com/你的用户名/work-memo-alarm.git
   ```

> 💡 如果 GitHub 打不开或很慢：用手机热点/换个网络试；或改用 **Codemagic**（https://codemagic.io，
> 对 Flutter 支持最好，iOS 签名也更方便，同样免费额度可用）。文末有说明。

---

## 第 2 步：把代码推上去（约 2 分钟）

我已经帮你把本地仓库初始化好并做了首次提交，**你只需要执行下面 3 条命令**。

打开终端（Windows 用 PowerShell 或 Git Bash），进入项目目录：

```bash
cd C:/Users/Administrator/WorkBuddy/2026-09-09-10-34-17/work_memo_alarm
```

然后执行（把地址换成你自己的）：

```bash
# ① 告诉 git 你是谁（只需做一次，换成你的名字和邮箱）
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"

# ② 关联远程仓库（换成你自己的地址）
git remote add origin https://github.com/你的用户名/work-memo-alarm.git

# ③ 推送（会弹出登录窗口，用 GitHub 账号登录；若用 Token，密码处粘贴 Personal Access Token）
git branch -M main
git push -u origin main
```

**关于登录**：新版 GitHub 不再接受密码，需要用 **Personal Access Token**：
1. GitHub 右上角头像 → **Settings** → 最下方 **Developer settings** → **Personal access tokens** → **Tokens (classic)** → **Generate new token (classic)**
2. 勾选 `repo`（全部子项）
3. 生成后**复制保存**（只显示一次）
4. 执行 `git push` 时：用户名填你的 GitHub 用户名，**密码处粘贴这个 Token**

> 更省事的方式：安装 [GitHub Desktop](https://desktop.github.com/)，图形界面登录，
> 把项目文件夹拖进去，点 "Publish repository" 即可，完全不用记命令。

---

## 第 3 步：等云端构建，下载安装包（约 10 分钟）

1. 推送成功后，打开你的仓库页面 → 点上方 **Actions** 标签
2. 会看到正在运行的任务（黄色圆点 = 运行中，绿色 ✓ = 成功，红色 ✗ = 失败）
3. 点进任务 → 最下方 **Artifacts** 区域，下载：

| 产物名 | 内容 | 用途 |
| --- | --- | --- |
| **android-apk** | 4 个 APK 文件 | **安卓手机安装用** |
| android-apk-signed | 正式签名 APK（配置密钥后才有） | 上架应用市场用 |
| ios-unsigned-app | 未签名 iOS 包 | 有 Mac 时重签名用 |

### 安卓应该下载哪一个？

| 文件名 | 适用 |
| --- | --- |
| `app-arm64-v8a-release.apk` | **绝大多数现代安卓手机选这个**（2018 年后的机型） |
| `app-armeabi-v7a-release.apk` | 老款 32 位手机 |
| `app-x86_64-release.apk` | 平板/模拟器，一般不选 |
| `app-debug.apk` | 体积最大，调试用 |

> 不确定就先下 `app-arm64-v8a-release.apk`，装不上再换 `armeabi-v7a`。

## 第 4 步：安装到安卓手机（约 2 分钟）

**传文件到手机**（任选一种）：
- 微信/QQ 发给"文件传输助手"，手机端下载
- 数据线连接电脑，复制到手机存储
- 上传到网盘，手机下载

**安装**：
1. 手机文件管理器里点开 APK
2. 系统提示"未知来源应用" → 点 **设置 / 允许**
   - 华为：设置 → 安全 → 更多安全设置 → 安装未知应用
   - 小米：设置 → 应用设置 → 安装未知应用（或点安装时会自动弹窗）
   - OPPO/vivo：安装时会直接提示，按引导开启
3. 安装完成后打开，桌面上会出现"工作备忘录"图标

**首次打开请务必做三件事**（否则闹钟可能不响）：
1. 弹窗询问通知权限 → 点 **允许**
2. 提示"精确闹钟权限" → 点 **去开启**，在系统设置里打开开关
3. 提示"电池优化白名单" → 点 **去开启** → 选择 **允许**

> 打开 APP 后，右下角「设置」页可以随时查看这三项权限的状态，绿色 ✓ 就是正常。

## 第 5 步：苹果 iPhone 安装（重要说明）

⚠️ **云端无法直接产出能安装到 iPhone 的包**，这是苹果的安全机制（所有 iOS App 必须经苹果签名），
与用什么工具打包无关，Flutter 也不例外。云端那个 `ios-unsigned-app` 只是帮你省去编译等待。

### 方案 A：你有 Mac 电脑（免费 Apple ID 即可，重装周期 7 天）
1. 从 GitHub 下载源码（Actions 里也可以直接下载 `ios-unsigned-app` 省编译）
2. Mac 上用 Xcode 打开 `ios/Runner.xcworkspace`
3. 左侧选 Runner → **Signing & Capabilities** → 勾选 **Automatically manage signing**
4. Team 选 "你的名字 (Personal Team)" —— 用你自己的 Apple ID 登录即可，**不需要付费**
5. 数据线连上 iPhone → Xcode 左上角选择你的手机 → 点 ▶ 运行
6. 手机上：设置 → 通用 → VPN与设备管理 → 信任你的开发者证书

> 免费 Apple ID 的限制：签名有效期 **7 天**，到期后需要用 Xcode 重新运行一次；
> 最多注册 3 个 App ID。自用完全够。

### 方案 B：没有 Mac，但愿意办付费开发者账号（688 元/年）
用 **Codemagic**（https://codemagic.io）：
1. 用 GitHub 账号登录，导入本仓库
2. 在 Codemagic 里绑定你的 Apple 开发者账号（上传 API Key）
3. 它会自动完成签名，产出可直接安装的 IPA，或自动上传到 **TestFlight**
4. TestFlight 安装最方便：手机上装 TestFlight App，接受邀请即可安装，有效期 90 天

### 方案 C：既没 Mac 也不想付费
只能借/租一台 Mac（云 Mac 租赁如 macincloud 按小时计费），
或暂时**只用安卓版**。iOS 真机安装绕不开苹果签名，这一点没有捷径。

## 以后改代码怎么办？

改完代码后：
```bash
git add .
git commit -m "改了xxx"
git push
```
推送后云端自动重新构建，10 分钟后去 Actions 下载新的 APK，**不需要重新走一遍配置流程**。

## 常见问题

| 问题 | 原因 / 解决 |
| --- | --- |
| Actions 里任务一直是黄色不结束 | 首次构建要下载 Gradle 依赖，约 10~15 分钟，正常 |
| 构建失败：红色 ✗ | 点进任务看日志末尾的错误；把报错发给我，我来改 |
| 报错 `No pubspec.yaml found` | 推送时漏了文件，确认项目根目录下有 `pubspec.yaml` |
| 报错找不到 `android/gradlew` | workflow 已自动处理（会自动生成脚手架），若仍失败看日志发我 |
| APK 装不上 / 解析包错误 | 换一个 ABI 文件（arm64 ↔ armeabi-v7a）试试；确认安卓版本 ≥ 6.0 |
| 装上了但闹钟不响 | 见 docs/03：通知权限 + 精确闹钟权限 + 电池白名单三个都要开 |
| 想让代码保密 | 仓库设为 Private，注意每月 2000 分钟额度（iOS 任务按 10 倍时长计费，可暂时注释掉 ios job） |
| 想省 GitHub 额度 | 编辑 `.github/workflows/build.yml`，把 `branches: [main, master]` 删掉，只保留 tag 触发 |

## 备选：Codemagic（对 Flutter 更友好）

如果不想折腾 GitHub Actions，或主要想打 iOS 包：

1. 注册 https://codemagic.io（可用 GitHub 账号登录）
2. **Add application** → 选择你的仓库 → 类型选 Flutter
3. Workflow 设置：
   - Build for：勾选 Android / iOS
   - Build mode：Release
4. 点 **Start new build**，完成后在页面下载 APK / IPA
5. iOS 需要额外配置签名（Code signing 标签页上传证书），有付费账号的话可自动签名

Codemagic 免费额度：每月 500 分钟（macOS 机器），个人使用足够。
